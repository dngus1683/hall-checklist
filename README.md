# 웨딩홀 투어 체크리스트 PWA

엑셀 체크리스트를 아이폰에서 사용하기 좋은 모바일 웹앱으로 변환한 버전입니다.

## 기능
- 9개 섹션 단계형 입력
- 선택 버튼 / 숫자 입력 / 메모 / 10점 만족도
- 웨딩홀별 저장 및 복제
- 자동 임시 저장(LocalStorage)
- JSON 백업 내보내기/가져오기
- PWA 및 오프라인 캐시 지원

## 아이폰 설치 방법
1. 이 폴더를 GitHub repository에 업로드합니다.
2. GitHub의 Settings → Pages → Deploy from a branch → main / root 를 선택합니다.
3. 생성된 `https://아이디.github.io/저장소명/` 주소를 **Safari**에서 엽니다.
4. Safari 공유 버튼 → 홈 화면에 추가 → `Open as Web App` 활성화 → 추가.
5. 홈 화면의 '웨딩홀 투어' 아이콘으로 실행합니다.

## 주의
- 데이터는 현재 아이폰의 브라우저 저장공간에 저장됩니다.
- 아이폰/브라우저를 바꾸거나 사이트 데이터를 삭제하면 저장 데이터가 사라질 수 있으므로, 투어 후 '백업 내보내기'로 JSON 파일을 보관하세요.
- 두 사람의 휴대폰 간 실시간 동기화는 이 버전에 포함하지 않았습니다.
